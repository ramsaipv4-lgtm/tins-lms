# Trainer prep — Web foundation

## Before you start (prerequisites)
Node 22, the repo built once (`npm run build -w packages/web`).

## 45-minute self-study path
Read the registry comment, run the foundation test, build with the pseudo-locale.

## Worked example → faded example
Worked: the join page. Faded: add a placeholder route to one group.

## Top misconceptions
- "Strings are only for translation": they also prove no literals remain.
- "Each group needs a router entry": the glob finds them.

## Questions students will ask (with answers)
- Why a checkbox for T&C? A checkbox works with both click and check in tests.

## Your mastery check (private)
Can the learner add a screen touching only their folder?
