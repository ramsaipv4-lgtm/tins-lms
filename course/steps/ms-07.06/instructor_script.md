# Instructor script — Shift, sprint rituals and the practice forge

**Total runtime: 40 minutes**

## 0:00 — 0:10: The question

**Say:** "Tickets must arrive over time. Who owns the clock?"

**Do:** Let learners pick between the three options, then reveal the choice.

## 0:10 — 0:25: Walkthrough

**Say:** "Read the ticket row. When is the answer cleared?"

**Do:** Point at the resolve condition, then show the server refusal for prod.

## 0:25 — 0:40: Faulty first

**Say:** "This was our bug on the slow phone. Fix it."

**Do:** Learners apply the one-line fix and run the Shift journey.
