# Recall — Shift, sprint rituals and the practice forge

**Q:** Where does elapsed Shift time come from?
**A:** The server clock, compared with the stored start time.

**Q:** What is stored in a shiftRun?
**A:** Start time, seed, mode and the events; state is replayed on every read.

**Q:** What must a prod deploy have?
**A:** An approved change request, otherwise the server refuses it.

**Q:** Why were button names like "Post" and "Submit" important?
**A:** The journeys match accessible names exactly, so extra words fail.
