# Activity key — Coach space (trainer only)

## Reinforcement activity: answer
Add `'extreme'` to `PATHWAYS`, give `hoursFor` a branch (for example 2 times the available hours, capped at 40), add strings for its name and trade-off, and test that its hours are greater than intense.

## Marking guide
| Criterion | Full marks when | Common partial answer |
|---|---|---|
| Code | the new card appears with hours and finish date | forgets the strings |
| Test | asserts ordering of hours | tests only one value |
