# Trainer prep — Teleprompter, substitute, trainer pack, rehearsal

## Before you start (prerequisites)
Run the tele test once so the build exists.

## 45-minute self-study path
Read Today.tsx, Prompter.tsx, then the server file's day route.

## Worked example → faded example
Worked: the learner poll. Faded: write the same poll for the handover read flag.

## Top misconceptions
- "The server sends the text early": it sends sealed bytes only.
- "Pace is saved": it is derived from local events.

## Questions students will ask (with answers)
- Why not websockets? No new dependency and the poll is enough.
