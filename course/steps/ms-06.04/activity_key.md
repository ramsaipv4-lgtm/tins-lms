# Activity key — Sync rules and the merge pass (trainer only)

## Reinforcement activity: answer
The ticket ends with the most advanced status (for example `done` over `doing`), a history unioned by id, and no `_conflicts` on the hub or either copy.

## Marking guide
| Criterion | Full marks when | Common partial answer |
|---|---|---|
| Prediction | names the status order todo < doing < review < done | says "the latest edit wins" |
| Observation | shows `_conflicts` absent after the pass | checks only one copy |
