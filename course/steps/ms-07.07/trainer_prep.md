# Trainer prep — Appeals, doubts, drop, accommodations, content improvement

## Before you start (prerequisites)
Learners know the feature registry (ms-07.01).

## 45-minute self-study path
Read the lesson, run `node --test packages/web/test/classroom.test.mjs`, then open the Grades screen as a learner.

## Worked example → faded example
Worked: the appeal decision route. Faded: write the same keep-the-original rule for a corrected attendance mark.

## Top misconceptions
- "Hiding a name in the page is enough." The data still reaches the device.
- "A loose label is fine." Tests use anchored accessible names.

## Questions students will ask (with answers)
- Why does the Shift timer not live here? The shift group owns it; this group only writes the accommodation.

## Your mastery check (private)
Explain why an accommodation request is not stored in the learner's own database.
