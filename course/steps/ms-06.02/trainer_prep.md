# Trainer prep — Pairing, devices, attendance

## Before you start (prerequisites)
Learners know status codes and the role guard from ms-06.01.

## 45-minute self-study path
Read the lesson, run the two test files, do the reinforcement activity.

## Worked example → faded example
Worked: claim a code twice. Faded: claim after expiry using the test clock.

## Top misconceptions
- "Revoking deletes the code": it removes the device's sessions.
- "Printed code is as good as rotating": it records verified false.

## Questions students will ask (with answers)
**Why 8 digits for printed?** So it cannot be mistaken for the 6-digit rotating code.

## Your mastery check (private)
Explain why the claim handler serialises, and which status a spent code gets.
