# Activity key — Packages, gate on upload, sealed sections (trainer only)

## Reinforcement activity: answer
Removing a required file such as a day's `deepdive.md` fails G1-files (and G2 if the README still lists it). Upload returns status draft with those checks; publish returns 409.

## Marking guide
| Criterion | Full marks when | Common partial answer |
|---|---|---|
| Predicts the failing check | Names the right G-id and why | Says "the gate fails" without an id |
| Explains publish refusal | Draft cannot publish, 409 with checks | Only says it errors |
