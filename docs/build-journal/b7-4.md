# b7-4: Teleprompter, substitute, trainer pack, rehearsal

**SPEC rows:** AC-83, AC-150, AC-151, AC-157, AC-158   **Model:** claude-sonnet-5-5   **Commits:** 940e3ba

## Decision
**Problem:** The learner's day page must show a section the moment the trainer taps next, without a reload, while sections stay sealed until released (D-38). A trainer must also be able to hand a day to a substitute or to self-learn mode, see a per-day pack, and rehearse with pacing.
**Options considered:** (1) websocket push; (2) poll a day view every 2 s and decrypt in the browser with `openSection`; (3) timed page reload. For the server: extend content.ts, or add read models in `routes/features/tele.ts`.
**Choice:** Poll (2) plus a separate `/api/tele/*` read-model module with `substitution`, `selflearn` and `rehearsal` documents in the class database. Pacing uses core `pace` over local entered-section events.
**Why:** No new dependency, works through the existing hub, the poll only ever receives a key for released sections, and content.ts stays untouched (out of scope).
