# b3-5: Recovery words and crypto-shredding

**SPEC rows:** AC-45, AC-46   **Model:** claude-sonnet-5-5   **Commits:** 3c4f923f66810152e55cb83088241066a64e62a0

## Decision
**Problem:** Show a 32-byte recovery key as words, wrap person keys, and erase a person by deleting their key.
**Options considered:** hex display; a word list with a checksum; one word per byte from a 256-word list; delete the data itself.
**Choice:** 256-word list in keys.ts, one byte per word; wrap with aesGcmSeal; shred returns a new keyring without that id.
**Why:** SPEC §4.25 fixes one byte per word; reusing util.ts keeps one AES-GCM implementation; not mutating the input avoids surprise for callers.
