# b4-1: Teleprompter pacing and script parsing

**SPEC rows:** AC-17, AC-18   **Model:** claude-haiku-4-5   **Commits:** [to be filled after commit]

## Decision

**Problem:** The instructor's teleprompter needs to track how far ahead or behind schedule the class is, and the script needs to be parsed to extract section timing information for release planning.

**Options considered:**
1. Parse time ranges from markdown headings and calculate actual vs planned duration
2. Use a simple regex to match heading patterns with times
3. Support multiple time formats (em dash, en dash, hyphen) for robustness

**Choice:** Implemented three functions:
- `pace()`: Calculates section-by-section pacing by tracking when the trainer entered each section and comparing actual duration to planned duration
- `parseScriptSections()`: Extracts headings from markdown with time ranges like `## Title (h:mm — h:mm)`, converts them to seconds, detects `[graded]` markers, and creates URL-safe slugs for section ids
- `scriptTotalSec()`: Extracts the total runtime from lines like `Total runtime: **45 minutes**`

**Why:** The spec requires:
- AC-17: Pace calculation must show section-by-section actual vs planned times, current section, and cumulative "behind" time
- AC-18: Script parsing must extract section blocks with durations and ignore headings without time ranges, handling various formatting (bold markers, multiple dash types)

The implementation:
- Uses simple regex parsing to be predictable and testable
- Converts time strings (h:mm format) to seconds for all calculations
- Creates slugs from titles by lowercasing and replacing non-alphanumerics with single dashes
- Tracks the current section by finding which section was entered most recently and hasn't been left yet
- Calculates behindSec as the sum of positive deltas (overages) for finished sections and any overrun in the current section

## What a learner will trip on

- Time calculation: The format is `(hours:minutes — hours:minutes)`, not just minutes. Learners may initially think `(0:15 — 1:15)` is 15 seconds to 75 seconds instead of 15 minutes to 75 minutes.
- Slug generation: Non-alphanumeric characters are collapsed into single dashes. Learners might expect multiple consecutive dashes or different handling of special characters.
- Graded sections: The `[graded]` marker can appear anywhere in the heading (before or after the time range). It's removed from the title and stored as a boolean flag.
- Current section detection: The current section is determined by which section was entered most recently. If no events have occurred, currentId is null.
- BehindSec interpretation: This is the cumulative overrun of finished sections plus any overrun in the current section. It's positive when the trainer is behind schedule, negative when ahead.
