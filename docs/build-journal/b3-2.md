# b3-2: Section keys and teleprompter-paced release

**SPEC rows:** AC-14, AC-15, AC-16   **Model:** claude-sonnet-5-5   **Commits:** fadc0ff

## Decision
**Problem:** Sections must be present on phones but unreadable until released; graded sections never open by time alone.
**Options considered:** send on release; plain text hidden by UI; per-section sealed keys with pure release functions.
**Choice:** HKDF per-section keys, AES-GCM seal/open via util.ts, pure `releasePlan` and `isReleased`.
**Why:** Offline-capable, testable with time as an argument (D-22), and the graded check precedes the time check (D-38).
