**SPEC rows:** none (SPEC §11, AC-140 to AC-144 apply to the course)   **Model:** claude-sonnet-5-5   **Commits:** see `git log` for this task's session

## Decision
**Problem:** The build tasks left 40 course steps written by the builders, with a missing step (ms-04.05), "Next" sections that said "end of chain", a few inconsistent headings, and none of the course-level material (syllabus, strategy, checkpoints, final project, appendices, marketing). The course had to say what was built and also teach the mistakes, from the journals only.
**Options considered:** (1) rewrite every step in one voice; (2) leave the steps alone and add only the new files; (3) a light mechanical editor pass over the steps (Next text, heading order, step line) plus the new files. For module 12 (AC-153 and AC-94, task b12-1, still in progress) either invent a lesson or say plainly that there is none yet. For the final project: any v2 feature in `docs/FEATURE-IDEAS.md` that SPEC §0 lists as not in v1.
**Choice:** Option 3, done with a script so that no code excerpt or `source_refs` entry could change. Module 12 has no lesson; the syllabus and checkpoint 6 say so and reason from the SPEC and the b7-8, b11-1, b11-2 journals. The final project is B-8 "evidence-linked resume bullets" (SPEC §0 lists it as not in v1), written as proposed AC rows with a model answer computed by a small reference script.
**Why:** The format evaluation found that a hand-edited course drifts from its files; a script keeps the chain exact, and the checks (`check.mjs`) catch the rest. A lesson for work nobody had finished would have been invented results.
