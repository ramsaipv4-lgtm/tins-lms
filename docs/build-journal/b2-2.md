# b2-2: Cards and spaced repetition (ts-fsrs)

**SPEC rows:** AC-3, AC-4, AC-5   **Model:** claude-haiku-4-5   **Commits:** 639065e

## Decision
**Problem:** Coach LMS learners study thousands of flashcards. We need to schedule reviews (when cards are due), filter due cards today, and spread overdue backlogs across days so learners don't burn out.

**Options considered:** 
1. Implement FSRS from scratch (20 tuned parameters, too complex)
2. Use ts-fsrs 5.4.2 library with wrapper for LMS's millisecond API
3. Hard-code "every 3 days" (ignores difficulty and performance)

**Choice:** Option 2 — ts-fsrs 5.4.2 with wrapper converting between Date and millisecond timestamps.

**Why:** FSRS is battle-tested in Anki; pure functions (time as parameter); handles rating order (again < hard < good < easy); spreadBacklog prevents overwhelming learners with all overdue cards on one day.
