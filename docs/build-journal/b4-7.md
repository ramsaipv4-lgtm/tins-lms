## What a learner will trip on

1. **Scope vs. task instructions mismatch:** Initial task says to include build/progress and docs/build-journal paths, but TASKS.md doesn't list them. Learners will commit those files, then kit close refuses because they're outside scope. Fix: trust TASKS.md, not the outer instruction.

2. **Multiple failed close attempts:** Each failure creates a "tins: uncommitted work at close" commit. Need to reset hard if scope is wrong.

3. **Using --why flag:** The flag tells kit that SPEC rows don't need to change (e.g., for metadata-only sessions). Always use it when not changing code.
